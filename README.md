# Shazia Omar — Portfolio

A monochromatic portfolio website for Shazia Omar — Bangladeshi novelist, social psychologist, yoga instructor, and founder of [The Flow Fest](https://theflowfest.com).

Built with Next.js and Tailwind CSS. Content and imagery sourced from [shazia.zilsoft.net](https://shazia.zilsoft.net).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Sections

- **Hero** — Introduction with cover imagery and tagline *gypsy heart*
- **About** — Biography, education, and personal highlights
- **Writing** — Published books and literary work
- **Yoga** — Classes, retreats, and the *Kundalini Rising* column
- **Flow Fest** — Founder spotlight for The Flow Fest wellness platform
- **Impact** — Development advocacy and social protection work
- **Contact** — Email and social links

## Tech Stack

- Next.js 16 (App Router)
- Tailwind CSS 4
- TypeScript
